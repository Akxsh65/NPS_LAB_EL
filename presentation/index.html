Can encrypted QUIC traffic still reveal which app you use?

Payloads are encrypted, but packet sizes, directions, and inter-packet times remain visible. We train deep learning classifiers on backbone traces, then measure how deterministic obfuscation (jitter, padding) trades privacy for bandwidth and latency cost.

What the attacker learns — no payload inspection

The privacy problem

QUIC hides content, not metadata. A passive observer can still fingerprint applications.

🔍 The attack

A Transformer encoder reads the first 30 packets of each flow as a sequence of timing + size features and predicts one of 64 application classes with 77.8% accuracy on held-out backbone data.

🛡 The defense

A privacy proxy reshapes metadata before it hits the monitored link: Laplace timing jitter (low / medium / high), 128 B size padding, or MTU padding — each with measurable overhead.

⭐ Key finding

jitter_low drops test-set accuracy by 0.93 percentage points (77.77% → 76.84%) with 11 ms mean latency overhead and 0% bandwidth on the Phase 4 manifest.
